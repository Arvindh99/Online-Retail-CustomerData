# 🛒 Online Retail Dashboard

A Streamlit-based interactive dashboard for exploring and analyzing customer purchasing behavior in an online retail dataset. The app provides insights through EDA visualizations, machine learning predictions, product recommendations, and RFM customer segmentation.

---

## 🚀 Features

### 📊 1. Exploratory Data Analysis (EDA)
- View top-selling products and top countries by sales.
- Visualize monthly sales trends and hourly sales distribution.

### 🤖 2. Purchase Probability Prediction
- Predict the likelihood of repeat purchases using a Random Forest classifier.
- Enter a Customer ID and Product Description to see purchase probability.

### 🎯 3. Product Recommendations
- Content-based recommendation system using cosine similarity on purchase behavior.
- Enter a Customer ID to get personalized product suggestions.

### 📊 4. RFM Analysis (Recency, Frequency, Monetary)
- Segment customers into: VIP, Frequent, Regular, Lost
- View distributions of RFM metrics and segment breakdowns.

---

## 🧠 Technologies Used

- Streamlit for web UI
- Plotly for interactive charts
- Pandas for data manipulation
- Scikit-learn for machine learning
- Cosine Similarity for recommendation system
